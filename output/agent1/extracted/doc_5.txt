Module 1 — Introduction à LangGraph
Théorie
LangGraph
est un framework Python créé par LangChain pour construire des agents et workflows IA basés sur des
graphes d'états
. Il permet de concevoir des flux complexes, cycliques et contrôlés, là où les simples chaînes LangChain atteignent leurs limites.
🤔 Pourquoi LangGraph ?
🔁
Cycles & Boucles
Contrairement aux DAGs, LangGraph supporte les cycles natifs — essentiel pour les agents qui réfléchissent en boucle.
📊
État explicite
L'état de l'application est typé et partagé entre tous les nœuds du graphe.
🧩
Modulaire
Chaque étape est un nœud isolé, facile à tester et à remplacer.
⏸️
Contrôle humain
Interrompre, inspecter et reprendre un workflow à n'importe quelle étape.
📐 LangGraph vs LangChain
Aspect
LangChain
LangGraph
Structure
Chaînes linéaires (DAG)
Graphes cycliques
État
Implicite
Explicite & typé
Boucles
Non supportées
Natives
Humain dans la boucle
Difficile
Intégré
Use case principal
RAG simple, chatbots
Agents complexes, orchestration
💡
LangGraph
complète
LangChain — vous pouvez utiliser les deux ensemble. LangGraph se concentre sur l'orchestration, LangChain sur les composants (LLMs, outils, parseurs).

Module 2 — Concepts Fondamentaux
Théorie
Les 4 piliers de LangGraph
1
📦 State (État)
Un dictionnaire typé (
TypedDict
) qui contient toutes les données partagées entre les nœuds. C'est le "cerveau" du graphe — chaque nœud peut le lire et le modifier.
2
⬡ Nodes (Nœuds)
Des fonctions Python qui prennent l'état en entrée, effectuent une action (appel LLM, outil, logique), et retournent les mises à jour de l'état.
3
➡️ Edges (Arêtes)
Les connexions entre nœuds. Peuvent être
fixes
(toujours le même chemin) ou
conditionnelles
(dépendent de l'état courant).
4
🏗️ Graph (Graphe)
L'assemblage de tout :
StateGraph
compile les nœuds et arêtes en un exécutable avec
.compile()
.
🗺️ Architecture Visuelle
Flux d'un agent ReAct typique
START
→
Agent
(LLM + décision)
→
si outil
Outils
(search, calc...)
→
boucle
si terminé
↓
END

Module 6 — Mémoire & Persistance d'État
Pratique
LangGraph supporte la
persistance
de l'état entre plusieurs invocations grâce aux
checkpointers
.
Types de Checkpointers
🧠
MemorySaver
En mémoire RAM. Simple, rapide, perd tout à l'arrêt.
🗄️
SQLite
Fichier local. Persist entre les runs, idéal en dev.
☁️
Postgres
Base distante. Pour la production multi-utilisateurs.
🔴
Redis
Cache rapide. Idéal pour états temporaires volumineux.

Module 7 — Human-in-the-Loop
Avancé
LangGraph permet d'
interrompre
l'exécution pour validation humaine, modifier l'état, puis reprendre — sans perdre le contexte.
Pattern : Interruption pour Validation

langgraph.checkpoint.memory
import
MemorySaver
from
langgraph.graph
import

typing
import
TypedDict

(f
"[PLANIFICATION] Tâche : {state['tache']}"
)

"Plan généré pour '{state['tache']}' : Étape1 → Étape2 → Étape3"
return
{
"plan"
: plan,
"validation_humaine"
:
False
}
def
executer
(state:
WorkflowState

"""Exécute après validation."""

"[EXÉCUTION] Plan validé, démarrage..."
)

{
"resultat"
: f

: {
"thread_id"

"job-001"

)

validation.lower() ==

None
, config=config)
