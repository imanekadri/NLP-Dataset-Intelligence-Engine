Module 1 — Introduction à LangGraph

Théorie

LangGraph est un framework Python créé par LangChain pour construire des agents et workflows IA basés sur des graphes d'états. Il permet de concevoir des flux complexes, cycliques et contrôlés, là où les simples chaînes LangChain atteignent leurs limites.

🤔 Pourquoi LangGraph ?

🔁

Cycles & Boucles

Contrairement aux DAGs, LangGraph supporte les cycles natifs — essentiel pour les agents qui réfléchissent en boucle.

📊

État explicite

L'état de l'application est typé et partagé entre tous les nœuds du graphe.

🧩

Modulaire

Chaque étape est un nœud isolé, facile à tester et à remplacer.

⏸️

Contrôle humain

Interrompre, inspecter et reprendre un workflow à n'importe quelle étape.

📐 LangGraph vs LangChain

AspectLangChainLangGraph
StructureChaînes linéaires (DAG)Graphes cycliques
ÉtatImpliciteExplicite & typé
BouclesNon supportéesNatives
Humain dans la boucleDifficileIntégré
Use case principalRAG simple, chatbotsAgents complexes, orchestration
💡

LangGraph complète LangChain — vous pouvez utiliser les deux ensemble. LangGraph se concentre sur l'orchestration, LangChain sur les composants (LLMs, outils, parseurs).

🔷

Module 2 — Concepts Fondamentaux

Théorie

Les 4 piliers de LangGraph

1

📦 State (État)

Un dictionnaire typé (TypedDict) qui contient toutes les données partagées entre les nœuds. C'est le "cerveau" du graphe — chaque nœud peut le lire et le modifier.

2

⬡ Nodes (Nœuds)

Des fonctions Python qui prennent l'état en entrée, effectuent une action (appel LLM, outil, logique), et retournent les mises à jour de l'état.

3

➡️ Edges (Arêtes)

Les connexions entre nœuds. Peuvent être fixes (toujours le même chemin) ou conditionnelles (dépendent de l'état courant).

4

🏗️ Graph (Graphe)

L'assemblage de tout : StateGraph compile les nœuds et arêtes en un exécutable avec .compile().

🗺️ Architecture Visuelle

Flux d'un agent ReAct typique
START
→
Agent
(LLM + décision)
→
si outil
Outils
(search, calc...)
→
boucle
si terminé ↓
END

Module 4 — Premier Graphe

Pratique

Construisons un graphe simple de traitement de texte : nettoyer → analyser → résumer.

Étape 1 — Définir l'État

python 
from typing import TypedDict, List, Optional
from langgraph.graph import StateGraph, END

# 1. Définir le schéma d'état
class TextState(TypedDict):
    texte_original: str
    texte_nettoye: str
    sentiment: str
    resume: str
    mots_cles: List[str]

Étape 2 — Définir les Nœuds

python 
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)

# Nœud 1 : Nettoyage du texte
def nettoyer_texte(state: TextState) -> TextState:
    """Supprime les caractères superflus et normalise le texte."""
    texte = state["texte_original"]
    texte_nettoye = texte.strip().replace("  ", " ")
    print(f"[NETTOYAGE] {len(texte)} → {len(texte_nettoye)} chars")
    return {"texte_nettoye": texte_nettoye}

# Nœud 2 : Analyse de sentiment
def analyser_sentiment(state: TextState) -> TextState:
    """Détermine le sentiment du texte via le LLM."""
    reponse = llm.invoke([
        {"role": "user", "content": f"""
Analyse le sentiment de ce texte en UN SEUL MOT parmi : 
positif, négatif, neutre, mitigé.

Texte : {state['texte_nettoye']}
        """}
    ])
    return {"sentiment": reponse.content.strip()}

# Nœud 3 : Résumé et mots-clés
def resumer(state: TextState) -> TextState:
    """Génère un résumé et extrait les mots-clés."""
    reponse = llm.invoke([
        {"role": "user", "content": f"""
Analyse ce texte (sentiment: {state['sentiment']}).
Réponds en JSON :
{{"resume": "1-2 phrases", "mots_cles": ["mot1", "mot2", "mot3"]}}

Texte : {state['texte_nettoye']}
        """}
    ])
    import json, re
    json_str = re.search(r'\{.*\}', reponse.content, re.DOTALL).group()
    data = json.loads(json_str)
    return {"resume": data["resume"], "mots_cles": data["mots_cles"]}

Étape 3 — Assembler le Graphe

python 
# Créer le graphe
graph = StateGraph(TextState)

# Ajouter les nœuds
graph.add_node("nettoyage", nettoyer_texte)
graph.add_node("analyse",   analyser_sentiment)
graph.add_node("resume",    resumer)

# Définir les arêtes (flux linéaire)
graph.set_entry_point("nettoyage")
graph.add_edge("nettoyage", "analyse")
graph.add_edge("analyse",   "resume")
graph.add_edge("resume",    END)

# Compiler
app = graph.compile()

# Exécuter !
resultat = app.invoke({
    "texte_original": """
    LangGraph  est  un outil  fantastique pour construire 
    des agents IA robustes et modulaires.  Il simplifie 
    énormément la gestion des états complexes.
    """
})

print(f"Sentiment  : {resultat['sentiment']}")
print(f"Résumé     : {resultat['resume']}")
print(f"Mots-clés  : {', '.join(resultat['mots_cles'])}")

Module 5 — Edges Conditionnels

Pratique

Les arêtes conditionnelles permettent de router dynamiquement l'exécution selon l'état courant — le cœur de la logique agentique.

Syntaxe de base

python 
# La fonction de routage retourne le nom du prochain nœud
def router(state: MonEtat) -> str:
    if state["condition"] == "a":
        return "noeud_a"
    elif state["condition"] == "b":
        return "noeud_b"
    else:
        return END

# add_conditional_edges(nœud_source, fn_routage, mapping_optionnel)
graph.add_conditional_edges(
    "noeud_decision",
    router,
    {
        "noeud_a": "noeud_a",   # retour → destination
        "noeud_b": "noeud_b",
        END: END,
    }
)

🤖 Exemple Complet — Agent ReAct

Implémentons le pattern Raisonnement → Action → Observation avec des outils.

python 
from typing import TypedDict, List, Annotated
from langchain_core.messages import BaseMessage, HumanMessage, AIMessage
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, END
from langgraph.graph.message import add_messages
import json

# ── État avec accumulateur de messages ──
class AgentState(TypedDict):
    messages: Annotated[List[BaseMessage], add_messages]
    nombre_tours: int

# ── Outils personnalisés ──
@tool
def calculer(expression: str) -> str:
    """Évalue une expression mathématique Python."""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"Erreur : {e}"

@tool
def météo(ville: str) -> str:
    """Retourne la météo simulée d'une ville."""
    donnees = {"paris": "18°C, nuageux", "lyon": "22°C, ensoleillé"}
    return donnees.get(ville.lower(), "Ville non trouvée")

outils = [calculer, météo]
outils_map = {t.name: t for t in outils}

# ── LLM avec outils liés ──
llm = ChatOpenAI(model="gpt-4o-mini").bind_tools(outils)

# ── Nœud Agent ──
def agent(state: AgentState) -> AgentState:
    reponse = llm.invoke(state["messages"])
    return {
        "messages": [reponse],
        "nombre_tours": state["nombre_tours"] + 1
    }

# ── Nœud Outils ──
def executer_outils(state: AgentState) -> AgentState:
    """Exécute tous les tool_calls du dernier message."""
    dernier_msg = state["messages"][-1]
    resultats = []
    for tool_call in dernier_msg.tool_calls:
        outil = outils_map[tool_call["name"]]
        resultat = outil.invoke(tool_call["args"])
        from langchain_core.messages import ToolMessage
        resultats.append(ToolMessage(
            content=str(resultat),
            tool_call_id=tool_call["id"]
        ))
    return {"messages": resultats}

# ── Routeur : continuer ou terminer ? ──
def doit_continuer(state: AgentState) -> str:
    dernier_msg = state["messages"][-1]
    # Si l'agent demande des outils → aller aux outils
    if hasattr(dernier_msg, "tool_calls") and dernier_msg.tool_calls:
        return "outils"
    # Si trop de tours → sécurité
    if state["nombre_tours"] >= 10:
        return END
    # Sinon → terminé
    return END

# ── Assemblage ──
graph = StateGraph(AgentState)
graph.add_node("agent",  agent)
graph.add_node("outils", executer_outils)

graph.set_entry_point("agent")
graph.add_conditional_edges("agent", doit_continuer)
graph.add_edge("outils", "agent")  # boucle retour

app = graph.compile()

# ── Test ──
reponse = app.invoke({
    "messages": [HumanMessage("Quelle est la météo à Paris ? Et combien fait 234 * 567 ?")],
    "nombre_tours": 0
})
print(reponse["messages"][-1].content)
✅

add_messages est un réducteur spécial : il accumule les messages au lieu de les remplacer. C'est le pattern standard pour les agents conversationnels.

Module 6 — Mémoire & Persistance d'État

Pratique

LangGraph supporte la persistance de l'état entre plusieurs invocations grâce aux checkpointers.

Types de Checkpointers

🧠

MemorySaver

En mémoire RAM. Simple, rapide, perd tout à l'arrêt.

🗄️

SQLite

Fichier local. Persist entre les runs, idéal en dev.

☁️

Postgres

Base distante. Pour la production multi-utilisateurs.

🔴

Redis

Cache rapide. Idéal pour états temporaires volumineux.

Implémentation avec MemorySaver

python 
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated, List
from langchain_core.messages import BaseMessage, HumanMessage
from langgraph.graph.message import add_messages
from langchain_openai import ChatOpenAI

class ConvState(TypedDict):
    messages: Annotated[List[BaseMessage], add_messages]

llm = ChatOpenAI(model="gpt-4o-mini")

def chatbot(state: ConvState):
    return {"messages": [llm.invoke(state["messages"])]}

# ── Compilation AVEC checkpointer ──
graph = StateGraph(ConvState)
graph.add_node("chat", chatbot)
graph.set_entry_point("chat")
graph.add_edge("chat", END)

memory = MemorySaver()
app = graph.compile(checkpointer=memory)

# ── thread_id = identifiant de conversation ──
config = {"configurable": {"thread_id": "conv-123"}}

# Tour 1
r1 = app.invoke(
    {"messages": [HumanMessage("Je m'appelle Alice.")]},
    config=config
)
print(r1["messages"][-1].content)

# Tour 2 — L'agent SE SOUVIENT d'Alice !
r2 = app.invoke(
    {"messages": [HumanMessage("Quel est mon prénom ?")]},
    config=config  # même thread_id = même mémoire
)
print(r2["messages"][-1].content)  # → "Votre prénom est Alice."

# Inspecter l'état sauvegardé
state = app.get_state(config)
print(f"Nombre de messages : {len(state.values['messages'])}")

Persistance SQLite (production légère)

python 
from langgraph.checkpoint.sqlite import SqliteSaver

# Persistance sur disque entre les redémarrages
with SqliteSaver.from_conn_string(":memory:") as checkpointer:
    app = graph.compile(checkpointer=checkpointer)
    # ...

# Ou avec un fichier permanent
with SqliteSaver.from_conn_string("./conversations.db") as checkpointer:
    app = graph.compile(checkpointer=checkpointer)
    # Les conversations survivent aux redémarrages !

Module 7 — Human-in-the-Loop

Avancé

LangGraph permet d'interrompre l'exécution pour validation humaine, modifier l'état, puis reprendre — sans perdre le contexte.

Pattern : Interruption pour Validation

python 
from langgraph.checkpoint.memory import MemorySaver
from langgraph.graph import StateGraph, END
from typing import TypedDict

class WorkflowState(TypedDict):
    tache: str
    plan: str
    validation_humaine: bool
    resultat: str

def planifier(state: WorkflowState):
    """L'IA génère un plan."""
    print(f"[PLANIFICATION] Tâche : {state['tache']}")
    plan = f"Plan généré pour '{state['tache']}' : Étape1 → Étape2 → Étape3"
    return {"plan": plan, "validation_humaine": False}

def executer(state: WorkflowState):
    """Exécute après validation."""
    print(f"[EXÉCUTION] Plan validé, démarrage...")
    return {"resultat": f"✅ Tâche '{state['tache']}' accomplie !"}

graph = StateGraph(WorkflowState)
graph.add_node("planifier", planifier)
graph.add_node("executer",  executer)
graph.set_entry_point("planifier")
graph.add_edge("planifier", "executer")
graph.add_edge("executer",  END)

memory = MemorySaver()

# interrupt_before = liste des nœuds où s'arrêter
app = graph.compile(
    checkpointer=memory,
    interrupt_before=["executer"]  # ← pause avant exécution
)

config = {"configurable": {"thread_id": "job-001"}}

# ── Lancement : s'arrête avant "executer" ──
app.invoke({"tache": "Déployer en production"}, config=config)

state = app.get_state(config)
print(f"⏸️  Pause ! Plan proposé :\n{state.values['plan']}")
print(f"Prochain nœud : {state.next}")

# ── L'humain valide (ou modifie l'état) ──
validation = input("\nValider ce plan ? (o/n) : ")

if validation.lower() == "o":
    # Reprendre depuis là où on s'est arrêté
    resultat = app.invoke(None, config=config)
    print(resultat["resultat"])
else:
    # Modifier l'état avant de reprendre
    app.update_state(config, {"plan": "Plan alternatif : Étape1 seulement"})
    resultat = app.invoke(None, config=config)
    print("Exécuté avec plan modifié :", resultat["resultat"])
💡

Utilisez interrupt_after pour interrompre après l'exécution d'un nœud (pour inspection), et interrupt_before pour valider avant une action critique.

Module 8 — Systèmes Multi-Agents

Avancé

LangGraph excelle pour orchestrer plusieurs agents spécialisés qui collaborent sur des tâches complexes.

Architecture Superviseur → Agents

python 
from typing import TypedDict, List, Literal
from langchain_openai import ChatOpenAI
from langgraph.graph import StateGraph, END

llm = ChatOpenAI(model="gpt-4o")

class TeamState(TypedDict):
    tache: str
    resultats: List[str]
    prochain_agent: str
    tour: int

# ── Agent Chercheur ──
def agent_recherche(state: TeamState) -> TeamState:
    reponse = llm.invoke([{
        "role": "system", "content": "Tu es un expert en recherche. Trouve des informations précises."
    }, {
        "role": "user", "content": f"Recherche : {state['tache']}"
    }])
    return {
        "resultats": state["resultats"] + [f"🔍 RECHERCHE: {reponse.content[:200]}"],
        "tour": state["tour"] + 1
    }

# ── Agent Rédacteur ──
def agent_redaction(state: TeamState) -> TeamState:
    contexte = "\n".join(state["resultats"])
    reponse = llm.invoke([{
        "role": "system", "content": "Tu es un expert en rédaction claire et concise."
    }, {
        "role": "user", "content": f"Rédige un rapport sur '{state['tache']}' en utilisant : {contexte}"
    }])
    return {
        "resultats": state["resultats"] + [f"✍️  RAPPORT: {reponse.content[:300]}"],
        "tour": state["tour"] + 1
    }

# ── Superviseur ──
def superviseur(state: TeamState) -> TeamState:
    """Décide quel agent appeler ou si le travail est terminé."""
    if state["tour"] == 0:
        return {"prochain_agent": "recherche"}
    elif state["tour"] == 1:
        return {"prochain_agent": "redaction"}
    else:
        return {"prochain_agent": "FINI"}

def router_superviseur(state: TeamState) -> str:
    return state["prochain_agent"]  # "recherche", "redaction", ou "FINI"

# ── Construction du graphe ──
graph = StateGraph(TeamState)
graph.add_node("superviseur", superviseur)
graph.add_node("recherche",   agent_recherche)
graph.add_node("redaction",   agent_redaction)

graph.set_entry_point("superviseur")
graph.add_conditional_edges(
    "superviseur",
    router_superviseur,
    {"recherche": "recherche", "redaction": "redaction", "FINI": END}
)
graph.add_edge("recherche", "superviseur")
graph.add_edge("redaction", "superviseur")

app = graph.compile()

# Lancement
final = app.invoke({
    "tache": "Les avantages de LangGraph pour la production IA",
    "resultats": [],
    "prochain_agent": "",
    "tour": 0
})
for r in final["resultats"]:
    print(r[:100], "...")
